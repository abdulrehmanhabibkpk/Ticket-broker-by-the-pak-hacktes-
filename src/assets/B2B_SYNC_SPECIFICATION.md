# TICKET BROKER: B2B Ticket Booking Sync Specifications
> Built by **The Pak Hacktes Team** for seamless Web & Android client synchronization.

This document contains the exact database architectures, collection schemas, state parameters, and UI design colors utilized in the Ticket Broker Web Portal. Use this specification to implement and configure the corresponding Android mobile client perfectly.

---

## 🗄️ 1. Firebase Firestore Collections Schemas

### A. `tickets` Collection (STRICT Flight Inventory)
Each document in the `tickets` collection represents a live available flight schedule. 
- **Firestore Document ID**: Auto-generated by Firebase (`addDoc` / `collectionRef`).
- **Fields Schema**:
  | Field Key | Type | Example Value | Description |
  | :--- | :--- | :--- | :--- |
  | `airline` | `String` | `"FlyJinnah"` | Name of the airline carrier |
  | `pnrPrefix` | `String` | `"9P"` | Flight identifier code prefix (uppercase) |
  | `origin` | `String` | `"ISB"` | Departure airport/city code (uppercase, 3 chars) |
  | `destination` | `String` | `"SHJ"` | Arrival airport/city code (uppercase, 3 chars) |
  | `departureDate`| `String` | `"2026-12-25"` | Format as standard `YYYY-MM-DD` date string |
  | `price` | `Number` | `98000` | Seat ticket price in PKR (or Double) |
  | `totalSeats` | `Integer`| `150` | Maximum plane capacity |
  | `availableSeats`| `Integer`| `148` | Remaining bookable inventory |

---

### B. `bookings` Collection (Passenger Dossiers Stream)
Stores real-time flight bookings placed by active travel agents.
- **Firestore Document ID**: Unique Booking ID generated upon placing the order.
- **Fields Schema**:
  | Field Key | Type | Example Value | Description |
  | :--- | :--- | :--- | :--- |
  | `bookingId` | `String` | `"z8Y1xPqpLw3m..."` | Auto-generated or custom booking reference |
  | `ticketId` | `String` | `"YqK9x2Lp1M..."` | ID of the corresponding document in `tickets` |
  | `agentName` | `String` | `"Al Harmain Travel"`| B2B agency corporate display name |
  | `agentEmail` | `String` | `"agent.partner@gmail.com"` | Corporate email of the purchasing agent |
  | `passengerName`| `String`| `"Jane Smith"` | First & last name of the passenger |
  | `passengerPassport`| `String`| `"PPT87654321"` | Passenger Passport / Document ID |
  | `passengerPhotoUrl`| `String`| `"data:image/jpeg;base64..."` | Compressed JPG Base64 avatar image |
  | `passportPhotoUrl` | `String`| `"data:image/jpeg;base64..."` | Compressed JPG Base64 passport scan |
  | `status` | `String` | `"Pending"` or `"Confirmed"` | Real-time seat reservation status |
  | `timestamp` | `Timestamp`| `serverTimestamp()` | Creation time |

---

### C. `ledgers` Collection (Agency Account Balance)
Financial ledger records representing deposits (credits) and ticket purchases (debits).
- **Firestore Document ID**: Auto-generated by Firebase.
- **Fields Schema**:
  | Field Key | Type | Example Value | Description |
  | :--- | :--- | :--- | :--- |
  | `agentEmail` | `String` | `"agent.partner@gmail.com"` | Target B2B agent email |
  | `agentName` | `String` | `"Al Harmain Travel"`| Agency display name |
  | `type` | `String` | `"Credit"` or `"Debit"` | Transaction direction entry |
  | `amount` | `Number` | `500000` | Transacted amount in PKR |
  | `description` | `String` | `"B2B Ticket Purchase: ISB to SHJ..."` | Description text of transaction |
  | `timestamp` | `Timestamp`| `serverTimestamp()` | Creation time |

*Note: The available balance limit of an agent is mathematically calculated as:*
$$\text{Ledger Balance} = \sum(\text{Credits}) - \sum(\text{Debits})$$
*(Default trial balance starting value if ledger has zero items is PKR 500,000)*

### D. `notifications` Collection (Alert Broadcasts)
Global notices published by the Admin.
- **Firestore Document ID**: Auto-generated by Firebase.
- **Fields Schema**:
  | Field Key | Type | Example Value | Description |
  | :--- | :--- | :--- | :--- |
  | `title` | `String` | `"New KSA Visa Guidelines"` | Title header |
  | `content` | `String` | `"Please make sure passport scans are clean..."` | Full text body |
  | `type` | `String` | `"info"`, `"alert"`, or `"promo"` | Visual category class |
  | `timestamp` | `Timestamp`| `serverTimestamp()` | Publishing time |

## 🎨 2. Visual Identity & Premium Color Palettes

To maintain design consistency across Web and Android, use these exact hex parameters:

  - Used for sidebar backgrounds, primary buttons, tables header bar, and main headings.

## 📱 3. Essential Android Architecture Guidelines

1. **Authentication Observer**:
   - Verify emails of all normal B2B Agents using standard `FirebaseUser.isEmailVerified()`.
   - Admin account is identified strictly when email is equal to `abdulrehman654as@gmail.com`.

2. **Real-time Synchronization**:
   - Use `FirebaseFirestore.getInstance().collection("tickets").addSnapshotListener(...)` to get instant, lag-free seat inventory counters on the mobile home screen.

3. **Passenger Document Compression**:
   - When capturing a passenger photo or passport scan using the phone's camera, compress the bitmap to a maximum resolution of `400x400px` at `70% JPEG quality`. Convert it to a Base64 string before uploading to `passengerPhotoUrl` and `passportPhotoUrl` fields. This maintains swift syncing without Firestore limits.
